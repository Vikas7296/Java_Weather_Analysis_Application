# Java Weather App 🌦️

## Project Overview
A desktop weather application developed using Java Swing that allows users to retrieve current weather information for a selected city.

## Features
- Search weather information by city name.
- Display weather details using the OpenWeatherMap API.
- Maintain a history of weather searches.
- Reset the displayed results.
- Simple graphical user interface built with Java Swing.

## Technologies Used
- Java
- Java Swing
- OpenWeatherMap API
- IntelliJ IDEA

## How It Works
1. Enter a city name.
2. Click the **Get Weather** button.
3. The application requests weather data from the OpenWeatherMap API.
4. The weather information is displayed in the application.
5. View previous searches using the history feature.

## Security
The API key should be stored securely and must not be committed to a public repository.
